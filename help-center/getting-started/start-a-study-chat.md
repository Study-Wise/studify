# Start a study chat

Our app can turn your questions and class materials into a focused conversation and study resources. Here's how to get started.

## Start a conversation

1. Sign in or create an account if our app prompts you. Chats are saved to your account.
2. On the home page, choose the subject and mode that best match what you're studying. You'll land in a new chat.
3. Type or paste your question into the message box, then send it. A clear prompt with the topic and what you're stuck on gives the conversation a useful starting point.
4. Ask follow-up questions in the same chat to keep the context together. You can ask for an explanation in different words, or focus on one step that feels confusing.

If you have notes or an assignment to use as context, attach it through **Upload Files** in the chat sidebar. See <<[Upload class materials](../study-tools/upload-class-materials)>> for file types and limits.

## Make study materials

After you send a message, use the sections in the chat sidebar to generate study materials from the conversation. You can return to the chat from a material page using **Back to Chat**. Each chat keeps its own conversation and generated materials, so start a new chat when you want to keep topics separate.

If something about our app isn't working, I'm here to help with app questions, and you can also reach [our support team](https://studywise.adarshrkumar.app/support). I can't help with the class material itself, but you can ask about it in one of the study modes on the home page.
