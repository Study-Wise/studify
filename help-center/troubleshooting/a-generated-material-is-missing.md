# A generated material is missing

Each study material belongs to the chat it was generated from. If you can't find one, these checks should help.

## Check the chat and sidebar

Open the conversation where you asked about the topic. In its right-hand sidebar, find the section for the material you want. If you have more than one chat about the same topic, check that you're in the conversation where you generated it. Materials don't automatically carry over between chats.

If the section says nothing has been generated yet, choose **Generate**. For additional resources, choose **Find**. A message needs to be sent in the chat before you can generate a material.

## If generation is still running or failed

You can keep chatting while generation runs. When it's ready, the material should appear in its sidebar section. If it seems stuck, give it a little more time, then refresh the page and check the section again.

If you saw an error, try generating it again. If you're regenerating a material that already exists, confirm the prompt. The new version replaces the existing one. You can add more context or clarify what you need in the chat before trying again.

If the material still doesn't appear, check that you're signed in to the account that owns the chat. You need access to the chat to view its materials.

If generation keeps failing or the material is still missing, [contact our support team](https://studywise.adarshrkumar.app/support). Tell us which type of material you tried to make, which chat you were in, and what happened, including any error message. Please don't send your password or other sensitive information.
