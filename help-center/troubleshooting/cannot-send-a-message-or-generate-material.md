# I can't send a message or generate material

If a message won't send, or the **Generate** button doesn't work, start with the checks below.

## Check your account and the chat

Make sure you're signed in to the account that owns the chat. Only the chat owner can send messages and generate materials. If you're viewing a public chat that someone shared with you, you can read it and open its materials, but you can't add to it. To study the topic yourself, start your own chat from the home page.

Study materials are made from the conversation, so you must send at least one message in the chat before you can generate anything. If a material section says nothing has been generated yet, send a message first, then choose **Generate**. For additional resources, choose **Find**.

## Check the chat limits

Each account can have up to 5 chats, and each chat can hold up to 10 of your messages. If you've reached a limit, our app shows a message saying so.

- **Too many chats:** delete a chat you no longer need, then start a new one. See [Delete a chat](../account-and-sharing/delete-a-chat).
- **Too many messages in a chat:** start a new chat from the home page and continue there. Generated materials stay with the chat they were made in.

We don't have paid plans yet. If you'd like one, [let us know](https://studywise.adarshrkumar.app/support), since a paid plan would increase these limits.

## Refresh and try again

If neither of those fits, refresh the page and send your message again. If an error appears while a reply is being written, send the message again. If generation fails, see [A generated material is missing](a-generated-material-is-missing).

If you still can't send a message or generate material, [contact our support team](https://studywise.adarshrkumar.app/support). Tell us which chat you were in, what you tried, and any error message you saw. Please leave out your password and any private information from your class materials.
