# A chat or page will not open

If a chat or study material page won't open, start with the checks below.

## Check your account and the chat's visibility

Make sure you're signed in to the account that owns the chat. Only the owner can access private chats. Public chats can be opened by people who are signed in and have the link. If someone shared a chat with you, ask them to check that **Thread Visibility** is set to **Public**.

If you're the owner but the chat isn't in **My Chats**, check whether you're signed in with the same account you used to create it. If you have multiple accounts, sign out and sign back in with the account that owns the chat.

If you just received a public link, make sure you have the full link and are signed in before opening it. Public chats are available to signed-in visitors while public sharing is on. If the owner turns sharing off, the link won't give you access.

## Refresh and try again

Refresh the page and reopen the chat from your profile or the shared link. If the link opens an error page, check that it wasn't cut off when it was copied, then try it in a new tab. You can also return to your profile and open the chat from **My Chats**.

If a chat opens but a study material page doesn't, go back to the chat and open the material from its sidebar. This also helps confirm you're using the right chat and link.

If you still can't get in, [contact our support team](https://studywise.adarshrkumar.app/support). Include the page or chat link, what you expected to see, and any error message. If someone shared the chat with you, mention that too. Please leave out your password and any private information from your class materials.
