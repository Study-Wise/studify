# Upload class materials

You can attach files to a chat to give our app context from your homework, notes, or other class materials. Upload them from the **Uploaded Files** section in the left-hand chat sidebar.

## Add a file

1. Open a chat in the subject mode that fits your class. You can upload from an existing chat or a new chat. If it's new, our app creates the chat when you start the upload.
2. In the left sidebar, choose **Upload Files** under **Uploaded Files**.
3. Select one or more files. You can upload images, PDFs, Word documents, PowerPoint presentations, Excel spreadsheets, and text files. Each file can be up to 10 MB.
4. Wait for the upload to finish. The file name will appear in the **Uploaded Files** list. Then send a message about the material, such as what you want explained or which part you'd like to review.

Uploading a file adds it to that chat. You can remove an uploaded file using the delete control next to its name. Make sure you choose the chat where you want to use the material.

## If an upload doesn't work

Check that the file is a supported type and no larger than 10 MB, then try again. If the upload still doesn't finish, check your connection and refresh the page, then try again. If it keeps failing, [contact our support team](https://studywise.adarshrkumar.app/support) with the file type, approximate size, and any error you saw. Please don't send private class records or passwords.
